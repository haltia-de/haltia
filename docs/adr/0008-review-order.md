# 0008. Кто кого проверяет

Дата: 21 октября 2026. Статус: принято. Заменяет правило проверки из
ADR 0005 и ревьюера Codex для PR Claude из ADR 0007.

## Контекст

По ADR 0005 PR проверяет модель, которая его не писала: Claude проверяет
Codex и Grok, Codex проверяет Claude. В первых проверках 21 октября ревьюер
Codex дважды ответил «замечаний нет» там, где проверка Claude нашла
недочёты (`debian/changelog` в weather#2, склеенный комментарий в shell#2).

## Решение

Проверка идёт только сверху вниз:

| Автор PR | Проверяет |
|---|---|
| Grok | Codex или Claude |
| Codex | Claude |
| Claude | другой сеанс Claude: архитектор или свежий сеанс, не тот, что писал |

- Grok никого не проверяет. Codex не проверяет Claude.
- Если PR написал сам архитектор, его проверяет отдельный свежий сеанс
  Claude.
- Ревьюер в herdr (ADR 0007) остаётся способом запуска: для PR Grok это
  Codex только на чтение, для PR Claude — сеанс Claude.
- Сливает PR по-прежнему человек.

## Последствия

- Работа Claude больше не получает второго мнения другой модели; его
  заменяет сеанс Claude без контекста автора.
- Ревьюер Codex нужен только когда появятся PR Grok.
