# 0009. Архитектор сливает проверенные PR

Дата: 21 октября 2026. Статус: принято. Меняет полномочия архитектора из
ADR 0005.

## Контекст

По ADR 0005 архитектор открывает задачи и PR в других репозиториях, но не
сливает их: сливает человек. В первых задачах шага 4 PR копились и ждали
человека, хотя ревью по ADR 0008 уже прошло.

## Решение

- Архитектор сливает PR в репозиториях `haltia-de`, когда ревью по ADR 0008
  прошло без блокирующих замечаний. Решение человека, 21 октября 2026.
- Слияние — squash, ветка исполнителя удаляется.
- Не сливаются без человека: PR с блокирующими замечаниями; PR, после
  слияния которых сразу что-то выходит или публикуется (рабочие процессы по
  пушу в `main`, публикация репозиториев, сборка образа). Перед слиянием
  архитектор проверяет, что запускает пуш в `main`.
- Теги, выпуски и перенос тега `v1` в `ci` по-прежнему только с одобрения
  человека.
- Пуш в чужой `main` мимо PR по-прежнему запрещён.

## Последствия

- Работа доходит до `main` без ожидания человека; человек видит её в
  истории PR.
- Ошибку ревью больше никто не ловит до `main`; откат — новым PR.
