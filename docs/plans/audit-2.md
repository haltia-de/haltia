# Второй аудит стабильности, 22 октября 2026

Повторный проход по всей платформе после исправлений [первого
аудита](audit-fixes.md), по просьбе автора: стабильность и технические
ошибки, в том числе возможные взаимоблокировки. Образец метода и шкалы
важности — навык `python-code-review`; шесть аудиторов Claude читали
`origin/main` каждого репозитория, прогоняли тесты, `py_compile`, pyflakes,
shellcheck, actionlint, а находки проверяли по коду от начала до конца.
Отчёты целиком — локально у архитектора
(`~/.local/state/haltia-audit/2026-10-22/`).

## Средняя важность — задачи

- shell#31 (вместе с высокими): часы домашнего экрана после перевода времени,
  клавиатура без сторожа (PR #34), два замка запуска Firefox (FFX2-1).
- kit#8: зависший «Снимаю…», поиск камер на главном потоке, дети ffmpeg после
  убийства читателя, поток миниатюр и кэш без предела; фронтальная камера
  libcamera не распознаётся.
- text#3: удаление без вопроса, потеря несохранённой заметки, нет автосохранения.
- files#11: вставка без временного файла.
- messenger#24 (после видеозвонков): переподключение каждые 3 с, обрыв звонка
  при разрыве сокета сообщений, два соединения на один аккаунт, мёртвый фон
  при ошибке связки ключей, фото в памяти.
- video#13: блокирующие вызовы libmpv в потоке отрисовки, 63 МБ миниатюр.
- weather#7, calendar#9 (полночь), paint#9 (двойное сохранение, длинные
  имена, загрузки без срока, очередь миниатюр).
- packages#13: метапакеты пересобираются каждые 30 минут — случайные сбои
  `apk add`; публикация без проверки закреплённых пакетов; ключи в образах с
  плавающей версией. Слияние публикует сайт — по одобрению автора.
- ci#7: ключи и токен записи рядом с кодом сборки deb и Flatpak. Вступает в
  силу при переносе `v1` — по одобрению автора.
- gst-webrtc#2: следить за выходом gst-plugins-bad 1.28.4 в Alpine.
- device#30: сборка образа молча берёт старый пакет или пропускает программу;
  зависание загрузки на Wi-Fi; гонка сна с перезагрузкой Wi-Fi; звук и камера
  после сна.

Низкая важность — в отчётах, задачами по ходу работы.
