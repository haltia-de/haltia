# План: камера для программ — «Камера», `haltia_kit.camera`, libcamera

Составлен 21 октября 2026 после разбора вопросов с автором. Исследование —
[Программа и служба камеры](../research/2026-10-21-camera-app.md). Часть
[плана звонков](calls.md): работа 8 (видеозвонок) берёт отсюда источник
видео.

## Цель

Одна камера для всех: видео в звонке Сообщений, фото для человека и «сними
мне фото» из других программ (Раскраска и любые другие) — со снимком сразу в
обработку.

## Решения автора

| # | Решение |
|---|---|
| 1 | Одна программа «Камера» с режимом «снять для программы». Программа вызывает `haltia_kit.camera.take_photo()` и получает путь к файлу. Звонок берёт видео напрямую из общего источника, без «Камеры». |
| 2 | Снимок всегда сохраняется в `~/Изображения/Камера` — виден в Галерее, программа получает тот же файл. В коде каталог «Изображения» берётся через XDG, подпапка «Камера»; буквальный путь программа не собирает. |
| 3 | Сначала только фото: одна большая кнопка «Снять», после снимка — «Ещё раз» и «Готово»; таймер 3 с для съёмки себя. Без настроек, без видеозаписи; задней камеры пока нет — переключателя нет. |
| 4 | Открытая сама по себе «Камера» после снимка предлагает 2–3 крупные кнопки программ, которые объявили, что принимают фото (не зашитый список). |
| 5 | Одна камера — один пользователь: во время звонка «Камера» пишет «Камера занята звонком». Значок «камера включена» в панели — shell#17. |
| 6 | Формат кадра: сначала научить драйвер отдавать неупакованный RAW10 или RAW8 (если pass 1 MT6589 умеет); нет — своя заплата `MBBA` в libcamera. |
| 7 | Без PipeWire на старте: `libcamerasrc` напрямую. PipeWire — когда понадобятся Firefox или Flatpak. |
| 8 | Новые репозитории: `haltia-de/camera` (программа) и `haltia-de/libcamera` (пакет под именем Alpine с нашими заплатами). |
| 9 | Задняя камера A5142 — позже, на том же стеке, после видеозвонка. |

## Устройство

```
OV9760 → SENINF → pass 1 → /dev/video0 (драйвер, device)
   → libcamera: simple pipeline + soft ISP на процессоре (пакет libcamera)
      → libcamerasrc (GStreamer)
         ├→ haltia_kit.camera: видоискатель GTK 3, take_photo()
         │     └→ «Камера» и любая программа на kit
         └→ Сообщения: tee → vp8enc → webrtcbin и своё окошко (работа 8 звонков)
```

Порядок: голосовые звонки на планшете (пакеты webrtc, device#23) важнее —
камера идёт после них у сеанса устройства, а работы 4–5 начинаются сразу на
ПК.

## Ход работ

22 октября 2026:
- Работа 1 слита (device PR #22): приёмник CSI-2, кадры с OV9760.
- Работа 2 в виде неупакованного RAW10 не понадобилась. Драйвер отдаёт
  8-битный Bayer `SBGGR8` (device #27), программный ISP libcamera его
  принимает. Заплата `MBBA` не вошла.
- Работа 3: пакет `haltia-de/libcamera` 0.7.1_p1 (simple pipeline,
  OV9760, `software_isp` на процессоре) закреплён в образе.
- Работы 4 и 5: `haltia_kit.camera` в kit 2.3.x и программа «Камера» 0.1.0
  (видоискатель, «Снять», «Через 3 секунды», «Ещё раз», «Готово»,
  «Отправить», «Камера занята звонком»).
- Работа 6: отдельной кнопки «Снять фото» в Раскраске нет. С 4.8.0 фото,
  переданное из «Камеры» или «Галереи», открывается как новая раскраска.
- Работа 7: видеозвонок в Сообщениях берёт видео из того же источника
  libcamera, мимо окна «Камеры». Задняя камера A5142 не подтверждена.
