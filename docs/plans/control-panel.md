# План: панель управления агентами

Составлен 21 октября 2026 после разбора вопросов с автором. Исследование —
[Платформы и оболочки для агентов](../research/2026-10-21-agent-platforms.md)
и [Открытые оркестраторы](../research/2026-10-21-orchestrators.md).

## Цель

С одной стороны — веб-панель: следить за работой агентов, читать журналы,
подключаться к сеансам, смотреть статистику. С другой — работа в CLI, как
сейчас. И меньше зависимости от GitHub: ревью и решение о пуше — локально.

## Решения автора

| # | Решение |
|---|---|
| 1 | Порядок: сначала веб-панель, потом локальное ревью, потом смена оболочек исполнителей. |
| 2 | Панель — только на ПК (`localhost`); позже — через VPN, без открытого порта. Вне `localhost` — вход по паролю. |
| 3 | GitHub остаётся главным для кода, задач и выпусков. Ревью и решение о пуше — локально, до GitHub. Свой сервер Git не заводим. |
| 4 | Основа — подписки. Сторонняя оболочка — только там, где поставщик официально разрешает вход по подписке. Claude — только Claude Code. |
| 5 | Сначала пилот OpenHands Agent Canvas на день; если не пройдёт — собрать по частям. |
| 6 | Задания диспетчера в панели — только просмотр. Вмешиваться (написать, ответить, остановить) — в живых сеансах. |
| 7 | Статистика: по задачам (взято, сделано, заблокировано, время до слияния) и по моделям (сколько задач, сколько PR прошли ревью с первого раза) — сразу; расход подписок — насколько CLI это отдают; нагрузка ПК — позже. |
| 8 | Локальное ревью: проверяет модель по ADR 0008, пуш решает архитектор по ADR 0009. PR, которые что-то публикуют, и выпуски решает автор. |
| 9 | Уведомления: на рабочий стол ПК и в GitHub — сразу; на телефон — позже, вместе с VPN. |
| 10 | Журналы и сеансы хранятся 30 дней, потом остаётся итог в статистике. |
| 11 | Grok — пилот через OpenCode (SuperGrok там разрешён официально). Codex пока остаётся в Codex CLI. |
| 13 | herdr остаётся для управления агентами из CLI (ADR 0007). Для веба — родные интерфейсы (Claude Remote Control, `opencode web`) и `zellij web` только на чтение. Окончательно — после пилота. |

## Пилот OpenHands Agent Canvas (день, ещё не начат)

На одной тестовой папке, не на настоящих репозиториях. Диспетчер и таймер в
это время работают как раньше. Шаги по порядку, остановка на первом провале:

1. **Условия Anthropic:** разрешён ли вход по подписке через официальный
   адаптер `claude-agent-acp`. Нет — Claude в пилоте не участвует.
2. **Agent Server в нашей песочнице bwrap** (ADR 0010: пустой дом, скрытые
   ключи, нет git и GitHub), веб-панель подключается к нему снаружи.
3. **Grok через ACP** (`grok agent stdio`).
4. **Статистика и журналы** по ACP-агентам.
5. **Локальный diff до пуша:** посмотреть и одобрить в панели без PR.

Итог — отчёт в `docs/research/`. Прошёл — ADR об устройстве панели.
Не прошёл — сборка по частям:

- Claude Remote Control для живых сеансов Claude;
- `opencode web` для GPT и Grok;
- своя небольшая панель поверх журналов и состояния диспетчера
  (`~/.local/state/haltia-dispatch/`): задания, статистика, diff до пуша;
- `zellij web` только на чтение.
