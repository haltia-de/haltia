# План: диагностические отчёты и «Почта»

Составлен 22 октября 2026 после разбора вопросов с автором (Q1–Q18).

## Решения автора

**Отчёты о сбоях**

| # | Решение |
|---|---|
| 1 | Письмо уходит по SMTP с почтового ящика человека через программу «Почта»; на планшетах нет ничего общего, своего сервера нет. |
| 2 | Перед отправкой вычищается личное: тексты сообщений, номера телефонов, токены, пароли, имена сетей и адреса, координаты. Системные сведения и ошибки остаются. Человеку список не показывается. |
| 3 | Сами отправляются отчёты о: падении программы (необработанное исключение), аварийном завершении процесса на C, зависании, закрытом оболочкой, сеансе, перезапускающемся по кругу, откате обновления, перезагрузке из-за сбоя ядра или сторожевого таймера (pstore), нехватке памяти (OOM). Не чаще одного письма в час; одинаковые — одним письмом со счётчиком; без сети — очередь. |
| 4 | Автоотправка молча; включается вместе с адресом помощника и выключается в «Для помощника». Кнопка «Отправить отчёт сейчас» есть всегда. |
| 5 | Состав: система (модель, ядро, версии пакетов, время работы, память, диск, батарея, качество Wi-Fi), состояние (процессы, демоны оболочки, блокировки сна, обновления, проверки здоровья, `packages.lock`), журналы (сеанс и демоны — последние ~300 строк, `/var/log`, `dmesg`, pstore, журналы программ), сам сбой (что, трассировка, когда, сколько раз). Без снимков экрана и данных человека. Один архив `.tar.gz` до ~5 МБ, сводка в тексте письма. |
| 6 | Планшет в письме — по имени, заданному помощником («Мама»), иначе по короткому автоматическому номеру (`b8k-7f3a`): «Haltia: сбой «Сообщения» — Мама (b8k-7f3a)». |
| 7 | Сбои ловят и kit (исключения Python, `faulthandler`), и оболочка снаружи (код выхода, закрытие зависшей программы, программы не на kit, C, OOM). |
| 8 | Сбор, очередь и отправку ведёт служба оболочки `haltia-report`; сведения, требующие root, — через `doas`, как обновления. Очередь в `/var/lib/haltia/reports/`: не больше 20 отчётов и не дольше 30 дней. |
| 10 | Ручной отчёт: необязательное поле «Что случилось?» и галочка «Приложить снимок экрана» (выключена). |
| 11 | Человеку ничего не показывается; в «Для помощника» — строка «Последний отчёт: отправлен … / не отправлен: …». |
| — | В «Для помощника» ещё «Системные журналы» (просмотр) и «Диагностический отчёт» (тот же отчёт: просмотр по разделам, «Сохранить в файл», «Отправить»). |

**«Почта»**

| # | Решение |
|---|---|
| 9 | Отдельная простая программа «Почта» для всей платформы: через неё настраивается ящик, уходят отчёты и вообще файлы. |
| 12 | Ящик — человека, один. Адрес помощника — поле «Куда отправлять отчёты» в «Для помощника». |
| 13 | Своя программа на kit в репозитории `haltia-de/mail`, IMAP и SMTP из стандартной библиотеки Python, сервер по домену, вход паролем приложения. OAuth пока не делаем (решение автора). |
| 14 | Первая версия: «Входящие», «Отправленные», «Корзина»; крупный список; чтение текстом (HTML в простой текст, картинки из интернета не грузятся); вложения — открыть, сохранить, «Отправить»; написать, ответить, переслать, адресная книга из переписки; приём файлов через «Отправить»; уведомление и счётчик на панели, проверка раз в 10 минут. Без фильтров, подписей, нескольких ящиков. |
| 15 | `haltia-report` передаёт письмо «Почте» через её службу на D-Bus без окна; «Почта» держит «Исходящие» и отправляет при сети; не настроена — отчёт ждёт в очереди `haltia-report`. |
| 18 | Пароль приложения — в хранилище kit (на планшете файл 0600 в папке «Почты»); «Выйти» удаляет его. |

## Ход работ

22 октября 2026:
- Работы 1 и 2 вышли в «Почте» 0.1.0: один ящик по паролю приложения,
  «Входящие», «Отправленные», «Корзина», письмо простым текстом, новое
  письмо с вложениями, приём файла через «Отправить». Программа скрыта с
  домашнего экрана (`NoDisplay`).
- Работа 3 частично: служба D-Bus `Send` и «Исходящие» есть (0.1.0, окно
  узнаётся оболочкой с 0.1.1). Уведомления и счётчик непрочитанных на
  панели в программе нет.
- Работа 4: `haltia_kit.crash` в kit 2.3.1 пишет исключения и файл
  faulthandler.
- Работы 5 и 6: оболочка 2.12.1–2.12.2. `haltia-report` собирает отчёт,
  чистит личное и передаёт его «Почте». В «Для помощника» есть адрес,
  имя планшета, автоотправка, «Отправить отчёт сейчас», журналы,
  просмотр отчёта и строка «Почта для отчётов».
- Работа 7 начата: ramoops на 1 МиБ в DRAM слит (device #40), чтобы oops
  сохранился целиком. Приёмка того, что `haltia-report` показывает после
  аварийной перезагрузки, этим планом не закрыта.
