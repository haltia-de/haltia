# Проверка готовности корневого репозитория к публичности

Дата проверки: 29 октября 2026, 13:30 UTC. Проверка выполнена только чтением;
видимость репозитория, история Git и продуктовые репозитории не менялись.

## Зафиксированная область

- Commit: `49a64ee7eac74b94cd42f866f26ad3d04c6ca8a0`.
- Tree: `b405fada1cd0003c5f99ed986aeffac332a37357`.
- 75 файлов точного committed tree; рабочее дерево при проверке чистое.
- Полная достижимая локальная история: 72 коммита всех имеющихся refs,
  222 уникальных blobs; репозиторий не shallow.
- Включён переносимый validation-набор r2: 15 файлов, включая два новых
  теста и исправления полноты результатов, очистки и снимков исходников.
- Исходные untracked drafts другого рабочего дерева не включены.

## Результат

**Подтверждённых секретов и явных приватных operational leaks не обнаружено.**

Использован официальный Gitleaks 8.30.1. Архив и файл контрольных сумм ранее
проверены по закреплённым SHA256 из официальных release metadata; архив
дополнительно сверен с checksum manifest. Сканирование выполнялось локально,
содержимое репозитория внешним сервисам не передавалось.

| Проверка | Результат |
|---|---|
| Gitleaks по всей достижимой истории (`--all --full-history`) | 2 кандидата, оба ложные срабатывания |
| Gitleaks по точному committed tree | Те же 2 ложных срабатывания |
| Подтверждённые секреты | 0 |
| Новые кандидаты относительно предыдущего аудита | 0 |
| Дополнительные private-marker patterns в blobs и commit messages | 0 подтверждённых leaks |
| Переносимые scripts и manifest: личные пути, account/token/log-payload markers | 0 кандидатов |

Оба срабатывания `generic-api-key` находятся в
`docs/research/2026-10-29-project-status.md:358` и `:391`: это публичные
Git commit SHA рядом со словом API. Строки побайтово совпали с ранее
независимо проверенными публичными SHA. Сканер завершился с exit 1 из-за
этих кандидатов; исходный результат сохранён, исключения не добавлялись.
Две находки в каждом режиме — две уникальные строки, не четыре секрета.

Дополнительные шаблоны проверяли private LAN IPv4, private/link-local IPv6,
MAC, явные hardware serial/IMEI/IMSI/ICCID, credential URL, private-key
markers, service-token patterns, личные home paths, email в текстовых
blobs и буквальные операционные команды с именами agent sessions.
В commit messages кандидатов нет.

Hostname-эвристика дала 17 исторических совпадений с именем файла локальных
инструкций; ещё 56 совпадений — намеренные project-workspace paths в
архитектурных и миграционных документах. Это классифицированные ложные
срабатывания или публичные проектные инструкции. Числа включают повторения
в исторических blobs, а не только строки текущего дерева.

Два RSA public PEM и OpenPGP keyring побайтово неизменны относительно ранее
проверенных публичных ключей. Секретных key packets тогда не было; новых
ключевых файлов или private-key markers не появилось. Public-key UID и
обычное авторство Git не трактуются как credentials.

В 15 файлах переносимого validation-набора не обнаружены личные абсолютные
пути, локальные package-origin aliases или account/token payload markers.
Эта проверка не запускала приложения, тесты или обновления и не обращалась
к планшету. Два опубликованных validation reports включены в общий tree scan.

## Пределы и последующие изменения

Нулевые подтверждённые findings не гарантируют отсутствия неизвестных
форматов секретов или неявно личной прозы; полного semantic DLP доказательства
эта проверка не даёт.

Вне области: недостижимые объекты и reflogs, удалённые remote branches,
GitHub issues/PR/comments, remote LFS objects, резервные копии и исходные
untracked drafts. Проверены все refs, имевшиеся локально на момент снимка.

Результат привязан к указанным commit и tree. Более поздние изменения,
включая commit с обновлением этого отчёта, требуют delta scan.
Изменение visibility остаётся отдельным решением человека и этим аудитом
не выполнялось. Полные отчёты сканера и file manifests сохранены приватно;
их содержимое и локальные operational values в этот документ не включены.
