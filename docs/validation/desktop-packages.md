# Приёмка настольных пакетов

Состояние: подготовка и исполнение первого изолированного прогона,
29 октября 2026. Область — weather, news, paint, music, messenger, video
и встроенная либо пакетная версия kit. Решения —
[план стабилизации](../plans/2026-10-29-project-stabilization.md).

## Метод

- Официальные подписанные репозитории Haltia; отдельная установка и
  тестовые XDG-профили. Рабочие установки, аккаунты и данные не изменяются.
- Flatpak — x86_64. Deb — Ubuntu noble/resolute и Debian trixie;
  Architecture: all либо реально собранный amd64, без обещания ARM-сборок.
- Для каждого результата: версия, ref/commit или SHA256 пакета, окружение,
  команда, код возврата и ограничение. Данные журналов очищаются от личного.
- Контейнерное разрешение зависимостей, импорт и headless smoke фиксируются
  отдельно от интерактивной приёмки. Фикстура сервиса не доказывает работу
  реального аккаунта. Пропущенная проверка отмечается not-run с причиной.

## Матрица

| Проверка | Ожидаемый результат |
|---|---|
| Подпись и источник | Проверены официальный источник, доверенный публичный ключ и контрольные суммы |
| Установка | Пакет ставится, зависимости разрешаются, версия соответствует артефакту |
| Запуск | Открывается новое окно из тестового профиля, без активации рабочего экземпляра |
| Основная операция | Есть ограниченный воспроизводимый сценарий программы без личного аккаунта |
| Перезапуск | Тестовые настройки и данные восстанавливаются |
| Нет сети | Ошибка понятна, интерфейс сохраняет управление |
| Обновление | Новая версия сохраняет тестовые данные предыдущей; это отдельная проверка от чистой установки |

Результаты прогона будут добавлены после проверки артефактов. До этого
ни одна строка матрицы не считается пройденной для всех программ.
